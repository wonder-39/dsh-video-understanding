# 交付物：Word 文档结构规范

主人要求：**每次看完视频，一律生成 .docx**。聊天里只放结论摘要，完整内容进文档。

## 三条全局规则（所有档位、所有类型）

1. **页脚**：`第 X 页 共 Y 页`（`docx_helpers` 自动生成，PAGE + NUMPAGES 域）。
2. **编号**：表格与图片在整份文档内**顺序编号**，写作 `表-1`、`图-1`；表题在表上方，图题在图下方。正文里可以写「见表-3」「见图-2」。
3. **不写「文字对账」板块**。ASR 校正结果存 `work/<slug>/corrections.md` 旁挂文件，文档的可靠性一节只写一句「校正 N 处，明细见旁挂文件」。

## 先判类别，再套模板

| 类别 | 包含 | 判据 |
|---|---|---|
| **观点类** | 教学、科普、经验分享、新闻、评论、访谈 | 有明确的「主张 / 结论 / 建议」；讲解人输出观点 |
| **赏析类** | 音乐 PV、娱乐搞笑、生活（含 vlog）、纯记录 | 以审美、情绪、趣味、记录为主，不输出可辩驳的主张 |

判据写进可靠性表。判错会导致模板错（多出或少掉「重点」板块）。

## 模板 A：观点类

### A1 批量档（每支视频一组）

```text
总览（批量档）
  表-1  素材 | 类型 | 一句话总结
        <视频1 标题>（<时长>） | <类型> | <一句话，含结论>
        <视频2 标题>（<时长>） | <类型> | <一句话>
        …

《视频1 标题》要点
  1. …
  2. …
  3. …（3–5 条）

《视频2 标题》要点
  1. …
```

判不出的条目不单设板块：总览表「一句话总结」写「无法判断（原因）」，要点段写「跳过」。

### A2 标准档

```text
总览（标准档）
  表-1  素材 | 类型 | 一句话总结

一、结构时间轴
  表-2  时间 | 段落 | 画面在做什么

二、逐段拆解
  1. <小标题>     图-N + 图注 + 分析段（1–2 段）
  2. <小标题>     图-N + 图注 + 分析段
  3. …

三、重点突出（对比）
  表-N  维度 | A | B        ← 有对比/数据必用表
  或 1./2./3. 编号列点       ← 无对比时

四、可靠性声明+评估
  表-N  项 | 情况
```

### A3 细致档

```text
总览（细致档）
  表-1  素材 | 类型 | 一句话总结

一、逐页表（换页时间由逐秒读帧确认）
  表-2  页 | 时间 | 页面内容

二、完整内容（图文把视频过一遍）
  图-N … + 图注 + 说明段（按内容分小节，视图文并茂）

三、重点细讲
  1. … 2. …（6–10 条，每条带时间或原文）

四、字幕全文（带时间段）
  表-N  时间 | 台词

五、可靠性声明+评估
  表-N  项 | 情况
```

## 模板 B：赏析类

| 档位 | 用哪套 | 差异 |
|---|---|---|
| 批量档 | **A1** | 与观点类完全相同（通用） |
| 标准档 | A2 | **删掉「三、重点突出」**，其余不变 |
| 细致档 | A3 | **删掉「三、重点细讲」**，其余不变 |

赏析类靠「逐段拆解 / 完整内容」承载判断，不另设重点板块。但**不能变成流水账**：每段仍要有一句“为什么这样写/这样拍”。

## 「重点」部分的内容规则

这是两类文档的分水岭，必须下功夫：

| 素材形态 | 呈现方式 |
|---|---|
| 两个及以上对象可对比（A vs B、方案 X vs Y） | **做对比表**（维度 / A / B），维度 5–9 行 |
| 有成组数据（时长、价格、分数、比例） | **做数据表**，并补一句换算或结论 |
| 没有表格可做，但有 3–5 个核心观点 | **编号列点**，每条一行、不超过 30 字 |
| 观点多且相互递进 | 标准档 3–5 条；**细致档 6–10 条**，每条带时间或原文引用 |

硬约束：

- 重点部分**不许写成大段散文**。
- 能表格化就表格化；表格优先于列点。
- 每条观点要么可核对（带时间戳 / 原文），要么明确标「我的判断」。

## 图片：按内容，不按数量

只有一条标准：**这张图承载了文字说不清的信息。**

- 该放就放；不该放一张都不加。批量档按主人要求 0 张。
- 每张配题注，说明它在证明什么，形如 `图-3　标题页：把观众的选择困难直接写成标题`。

## 生成方式

用 `load_workspace_dependencies` 返回的 Python（自带 python-docx 1.2.0）：

```python
import sys
sys.path.insert(0, r"C:\Users\jack\.dsh\skills\video-understanding\scripts")
from docx_helpers import Doc

d = Doc(path, image_dir=FRAMES)          # 页脚自动是「第 X 页 共 Y 页」
d.table(headers, rows, caption="总览", widths=[5, 3, 8])   # → 表-1 总览
d.image("01.png", "标题页：把矛盾写成标题")               # → 图-1
d.num_list(["…", "…"])                                   # 1. 2. 3.
d.save()
```

API 一览：`cover / h1 / h2 / para / note / quote / num_list / image / table / save`；
`table_label()` / `fig_label()` 取下一个编号，供正文引用。

## 交付前检查

1. 渲染 1–2 页与末页，确认：
   - 页脚「第 X 页 共 Y 页」里的 Y 与实际页数一致；
   - 表题在图上方、图题在图下方，编号连续无跳号；
   - 没有「文字对账」板块。
2. 有对比/数据的视频，确认「重点」板块是表不是散文。
3. 渲染目录用完即删（`.dsh-office-*`），不要留在工作区。
4. `present` 交付 .docx。
